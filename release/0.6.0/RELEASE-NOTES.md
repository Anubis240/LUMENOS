# Lumen OS 0.6.0 Preview

This preview adds the first graphical disk-installer build of Lumen OS. It combines the Lumen AI desktop with Debian 13, XFCE recovery tools, cloud account and API providers, optional local Ollama models, agents, automations, permission-gated Gmail context, and Lumen-themed native applications.

## Installer milestone

- Debian Calamares 3.3.14 with Lumen branding and bootloader naming.
- Lumen installer launcher in the desktop shell and XFCE menu.
- Live-session-only privilege wrapper for the passwordless preview account.
- Branded BIOS and UEFI boot menus, Plymouth splash, GTK/XFCE theme, and circuit artwork.
- Clean 0.6.0 ISO booted and opened the installer in isolated BIOS and UEFI VMs with blank 64 GB virtual disks.
