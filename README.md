# Lumen OS

Run `node serve.cjs` with Node.js 22 or later, then visit http://127.0.0.1:4173.

Open **Settings → AI & Voice** to use an existing ChatGPT or eligible Claude subscription through each provider's official command-line runtime, or connect separate OpenAI and Anthropic API keys. Gemini voice has its own key and account quota.

When **ChatGPT Account** is selected, conversations and agent tasks use the signed-in ChatGPT/Codex subscription limits. Lumen removes `OPENAI_API_KEY` from that runtime and never substitutes the separately saved OpenAI API key. **Claude Account** follows the same rule for Anthropic credentials. Developer API keys are optional, separately billed connections used only when their API provider is explicitly selected. New profiles use **ChatGPT Account** for raster images through Codex's built-in `$imagegen` skill. **Claude Account** can create sanitized SVG illustrations through Claude Code safe mode with all tools disabled. Both account routes count against their included subscription limits and never inherit developer API credentials. API image providers require an explicit billing opt-in and a named provider on every request; the backend never falls through to another provider. Completed images support download, deletion, and a full-screen viewer.

Version 0.6.0 adds an experimental graphical disk installer with Lumen branding, a live-session-only privilege wrapper, and a VM-tested blank-disk workflow. Version 0.5.1 added branded Lumen boot menus for BIOS and UEFI and fixed closing the Gmail connection dialog while OAuth was pending. Version 0.5 added a dedicated Integrations workspace with secure Google Account OAuth and permission-gated, read-only Gmail context for agents and automations. It also added a complete Lumen Linux theme for native GTK/XFCE windows, a branded Plymouth boot splash, and responsive circuit-board traces around the animated interface. Version 0.4 added ChatGPT and Claude account connections to the persisted agents, recurring automations, workspace notes, job activity, optional offline models and Linux desktop session from version 0.3. Account access uses the official Codex and Claude Code runtimes. Lumen does not receive or store their OAuth tokens. New schedules are paused by default. Enable both a routine and the scheduler when you want background work. The daily task limit covers agent jobs, not chat or voice, and is not a currency cap.

Graft 0.18.0 is wired into this checkout for Codex and Claude Code. Its structural graph is the local `graft/` cache and uses no API key or paid model. Run `./tools/graft.ps1 map`, `./tools/graft.ps1 ask "question" --source`, or `./tools/graft.ps1 viz --port 4181`. The project launchers and MCP configuration set `DO_NOT_TRACK=1`; restart Claude Code after cloning so it loads `.mcp.json`.

Do not include `runtime-private/` when copying or sharing the source. It contains local encrypted credentials on Windows, plus private workspace notes and task history. The supplied build and packaging scripts exclude it.
